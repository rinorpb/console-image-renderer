# console-image-renderer
Draws images in your console using the half characters, with colour!

Use -h or --help argument to see the following usage instructions:

>Renders an image in the console as ASCII characters  
>  
>Main usage:  
>console-image-renderer.exe [IMAGE] [WIDTH] [HEIGHT]  
>  
>Available arguments:  
>--help | -h : print this message  

Currently only built and tested on Windows.
